# Sections

## 1. Load Testing (load)

**Impact:** HIGH **Description:** Load tests catch capacity and latency regressions before they reach production traffic.

## 2. Web Vitals & Frontend Budgets (vitals)

**Impact:** HIGH **Description:** User-perceived performance is measured by specific, gateable metrics, not vague page-load impressions.

## 3. Profiling & Diagnosis (profiling)

**Impact:** MEDIUM **Description:** Once a regression is caught, profiling tools identify the actual bottleneck instead of guessing.
